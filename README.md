# Audit Service 📝

**This project contains a sample ASP.NET Core app. This app is an example of the article I produced for the Telerik Blog (telerik.com/blogs)**

This basic ASP.NET Core application demonstrates the use of techniques for optimizing and securing web APIs that handle data on the order of millions of records.

---

## ✨ Features Overview

- **Filtering**
- **Projections**
- **Indexing**
- **Key-based pagination**
- **Batch processing**
- **Resilience**
- **Rate limiting**
